# VisaGo — 签证百科模块开发 Prompt

## 背景

项目已搭建完成（Vite + Vue 3 + TSX + UnoCSS + Hono + SQLite + Kimi）。
现在只实现四个模块中的第一个：**签证百科 (Encyclopedia)**。
目标：把这个模块做精、做透，作为整个产品的数据基础和内容壁垒。

---

## 模块定位

签证百科是整个产品的地基：
- 为「申请助手」提供材料清单数据
- 为「AI 问答」提供知识库上下文
- 为「资料生成」提供模板参考
- 独立作为内容页，承载 SEO 流量

**核心体验**：用户进来 → 找到目标国家 → 一目了然知道怎么办签证 → 想深入有细节 → 想对比能对比。

---

## 页面清单

| 路由 | 页面 | 说明 |
|------|------|------|
| `/encyclopedia` | 国家列表页 | 搜索 + 筛选 + 国家卡片网格 |
| `/encyclopedia/:id` | 国家详情页 | 签证全信息，Tab 分区 |
| `/encyclopedia/compare` | 对比页 | 2-3 国横向对比 |

### 搜索框

- 圆角 pill 形，左侧搜索图标，placeholder「搜索国家名称...」
- 实时过滤（前端 filter，无需请求后端）
- 支持中文名、英文名、拼音首字母匹配
- 输入时显示匹配数量：「找到 3 个国家」
- 清空按钮（输入内容后右侧显示 ×）

### 筛选器

**难度筛选**（下拉单选）：
- 全部 / 容易 🟢 / 中等 🟠 / 困难 🔴

**区域筛选**（下拉单选）：
- 全部 / 东亚 / 东南亚 / 欧洲 / 北美 / 大洋洲

**组合筛选**：两个筛选可同时生效，结果取交集。

### 对比模式

- 工具栏右侧「对比模式」开关
- 开启后，卡片右上角出现圆形选择框
- 点击卡片 = 选中/取消（最多选 3 个）
- 底部浮出操作栏：「已选 2 个国家 → 开始对比」
- 点击跳转 `/encyclopedia/compare?ids=japan,korea`

### 国家卡片

**尺寸**：桌面端 4 列，平板 3 列，手机 2 列

**卡片内容**：
```
┌─────────────────────┐
│                     │
│       🇯🇵           │  ← 国旗 emoji，字号 48px
│                     │
│     日本             │  ← 中文名，16px 粗体

│                     │
│   ┌──────┐          │
│   │ 中等  │          │  ← 难度标签，pill 形
│   └──────┘          │
│                     │

│   ¥200 起            │  ← 最低费用
```

**交互**：
- hover：translateY(-4px) + box-shadow 加深，200ms ease
- 点击：整卡可点，跳转 `/encyclopedia/:id`
- 入场动画：卡片依次从下方淡入（stagger 50ms）

**难度标签配色**：
- 容易：背景 `#E8F5E9`，文字 `#2E7D32`
- 中等：背景 `#FFF3E0`，文字 `#E65100`
- 困难：背景 `#FFEBEE`，文字 `#C62828`

### 顶部 Banner

- 全宽，高度 220px（桌面端）/ 180px（移动端）
- 深蓝渐变背景，白色几何线条装饰
- 左侧：国旗 emoji（64px）+ 中文名（28px 粗体）+ 英文名（16px 半透明白）
- 中间：一句话概述（14px，白色 80% 透明度）
- 底部：4 个数据标签横排（难度 / 签证类型数 / 最低费用 / 办理周期）
  - 标签样式：白色半透明背景 pill，白色文字

### Tab 导航

- 粘性定位（`position: sticky; top: 64px`，在 Header 下方）
- 白色背景 + 底部阴影
- Tab 项：文字 + 下划线指示器（宝蓝色，2px）
- 当前 Tab 下划线跟随滑动过渡（300ms ease）
- 移动端：Tab 横向可滚动

## 五、数据结构

### 完整签证数据（7 国）

```ts
// server/src/data/countries.json
// 以下为数据结构示例，实际需填充完整数据

interface CountryData {
  id: string                    // "japan" | "korea" | "thailand" | "schengen" | "usa" | "uk" | "australia"
  name: { zh: string; en: string }
  flag: string                  // emoji
  difficulty: 'easy' | 'medium' | 'hard'
  region: '东亚' | '东南亚' | '欧洲' | '北美' | '大洋洲'
  overview: { zh: string; en: string }  // 一句话概述

  visaTypes: VisaTypeData[]
  visaFree: { zh: string; en: string }  // 免签政策说明
  announcements: AnnouncementData[]
}

interface VisaTypeData {
  id: string
  name: { zh: string; en: string }
  category: 'tourist' | 'business' | 'family' | 'transit' | 'student'
  duration: string              // "15天"
  validity: string              // "3个月"
  entries: 'single' | 'multiple'
  fee: { amount: number; currency: string }  // 使馆签证费
  serviceFee?: { amount: number; currency: string }  // 代办服务费
  processingDays: { min: number; max: number }
  needInterview: boolean
  canApplyOnline: boolean       // 是否支持电子签
  acceptPersonal: boolean       // 是否接受个人递签
  targetAudience: { zh: string; en: string }
  consularDistricts: DistrictData[]
  requirements: {
    basic: RequirementItem[]
    identity: {
      employed: RequirementItem[]
      student: RequirementItem[]
      retired: RequirementItem[]
      freelance: RequirementItem[]
    }
    financial: RequirementItem[]
    travel: RequirementItem[]
  }
  tips: { zh: string; en: string }
  rejectionReasons: { zh: string; en: string }[]
  faq: FAQItem[]
}

interface DistrictData {
  name: { zh: string; en: string }
  city: string                  // 使馆所在城市
  provinces: string[]
}

interface RequirementItem {
  id: string
  name: { zh: string; en: string }
  required: 'required' | 'recommended' | 'optional'
  format: 'original' | 'copy' | 'both'
  translationRequired: boolean
  details: { zh: string; en: string }  // 具体要求说明
}

interface FAQItem {
  id: string
  question: { zh: string; en: string }
  answer: { zh: string; en: string }
}

interface AnnouncementData {
  date: string                  // "2025-01-15"
  title: { zh: string; en: string }
  summary: { zh: string; en: string }
}
```

## 六、后端 API

```
GET  /api/countries
     → 返回所有国家列表（不含详细数据，仅 id/name/flag/difficulty/region）

GET  /api/countries/:id
     → 返回单个国家完整数据（含所有签证类型、材料、FAQ 等）

GET  /api/countries/compare?ids=japan,korea,usa
     → 返回多个国家的数据，用于对比页

POST /api/ai/chat
     → 签证百科 AI 问答（SSE 流式）
     Body: { messages: [...], countryId?: string }
     → System Prompt 自动注入对应国家的签证数据
```
